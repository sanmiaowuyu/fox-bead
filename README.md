# 狐狸爱拼豆 - 图片转拼豆图案工具

单文件 HTML 应用，零依赖，手机电脑皆可用。

## 快速使用

直接打开 `index.html` 即可运行，无需安装任何环境。

## 技术约束

- 单文件 HTML 部署（所有 CSS/JS 内联）
- 零外部依赖
- Mard 221 色板固定值不可修改
- 不使用 `?.` / `Object.fromEntries` / spread 操作符（旧移动端兼容）
- 保留 CSS 主题变量体系（`--accent` / `--accent-ink` / `--accent-soft` / `--accent-line`）
